# API Contract

This document describes the initial API contract for the AI IT Incident Classifier.

The API receives IT support incidents, validates the request payload, classifies the incident using a controlled triage contract and returns a structured response.

## Base Endpoints

### `GET /`

Returns basic service metadata.

Example response:

```json
{
  "service": "AI IT Incident Classifier",
  "status": "running",
  "version": "0.1.0"
}
```

### `GET /health`

Returns the API health status.

Example response:

```json
{
  "status": "healthy"
}
```

## Incident Classification Endpoint

### `POST /incidents/classify`

Classifies an IT support incident.

The current implementation uses a deterministic mock classifier. A later implementation will replace the mock classifier with Gemini API while preserving the same request and response contract.

### Request Body

```json
{
  "title": "No puedo conectarme a la VPN",
  "description": "Desde ayer intento conectarme a la VPN de la empresa, pero aparece error de autenticación.",
  "reported_by": "usuario.demo@empresa.com",
  "source_channel": "postman"
}
```

### Request Fields

| Field            |   Type | Required | Description                                             |
| ---------------- | -----: | -------: | ------------------------------------------------------- |
| `title`          | string |      yes | Short title describing the IT incident.                 |
| `description`    | string |      yes | Detailed description of the IT incident.                |
| `reported_by`    | string |       no | Optional email of the person reporting the incident.    |
| `source_channel` | string |       no | Channel used to report the incident. Defaults to `api`. |

## Validation Rules

| Field            | Rule                                                      |
| ---------------- | --------------------------------------------------------- |
| `title`          | Required, minimum 5 characters, maximum 120 characters.   |
| `description`    | Required, minimum 15 characters, maximum 2000 characters. |
| `reported_by`    | Optional valid email address.                             |
| `source_channel` | Must be one of `web`, `postman` or `api`.                 |

## Response Body

```json
{
  "incident_id": "INC-20260629-A3F91C2B",
  "category": "VPN",
  "priority": "Media",
  "responsible_area": "Infraestructura",
  "summary": "The incident was classified as VPN based on the provided title and description: No puedo conectarme a la VPN.",
  "suggested_action": "Validate user credentials, account status, VPN client configuration and VPN service logs.",
  "confidence_level": "Media",
  "needs_human_review": false,
  "model_name": "gemini-1.5-flash-mock",
  "created_at": "2026-06-29T10:30:00Z"
}
```

### Response Fields

| Field                |    Type | Description                                                          |
| -------------------- | ------: | -------------------------------------------------------------------- |
| `incident_id`        |  string | Unique identifier generated by the backend.                          |
| `category`           |  string | Controlled incident category.                                        |
| `priority`           |  string | Suggested operational priority.                                      |
| `responsible_area`   |  string | Suggested first responsible support area.                            |
| `summary`            |  string | Short technical summary of the incident.                             |
| `suggested_action`   |  string | Recommended first support action.                                    |
| `confidence_level`   |  string | Qualitative confidence level. This is not a statistical probability. |
| `needs_human_review` | boolean | Indicates whether the incident should be reviewed manually.          |
| `model_name`         |  string | Classifier model or runtime used to generate the result.             |
| `created_at`         |  string | UTC timestamp generated when the classification is created.          |

## Controlled Categories

The classifier must return one of the following categories:

- `VPN`
- `Redes`
- `Accesos`
- `Correo`
- `Hardware`
- `Sistema Operativo`
- `Base de Datos`
- `Aplicaciones`
- `Seguridad`
- `Cloud`
- `Otro`

## Controlled Priorities

The classifier must return one of the following priorities:

- `Baja`
- `Media`
- `Alta`
- `Crítica`

## Responsible Areas

The classifier must return one of the following responsible areas:

- `Soporte TI`
- `Infraestructura`
- `Seguridad`
- `Base de Datos`
- `Aplicaciones`
- `Cloud`

## Confidence Levels

The classifier must return one of the following confidence levels:

- `Baja`
- `Media`
- `Alta`

The confidence level is qualitative. It should not be interpreted as a statistical probability.

## Manual Review

The `needs_human_review` field must be set to `true` when:

- The incident description is unclear.
- The classifier cannot confidently assign a category.
- The classification falls under `Otro`.
- The model response is invalid or incomplete.
- The incident requires human judgment due to operational or security risk.

## Current Limitation

The current `/incidents/classify` endpoint uses a local mock classifier. This allows the API contract, validation rules and frontend integration to be developed before connecting the real generative AI classifier.
